# 客語動物園｜聽說遊戲 App

給幼教老師與 0-6 歲幼兒使用的客語學習 App。內容取材自《客語真好玩》第一冊
第 17 課「動物」，共 17 種動物（貓仔、狗仔、豬仔、雞仔、牛仔、馬仔、兔仔、
猴仔、羊仔、揚尾仔、土狗仔、火焰蟲、揚葉仔、老虎、獅仔、熊仔、鳥仔），
語音由陽明交大 BRONCI（長問科技）TTS API 提供。

## 功能

- 👂 **聽一聽**：點動物卡片，聽正確的客語發音，並可翻看客語字卡
- 🎮 **動物遊戲區**：
  - 🔗 連連看：動物圖片配對客語詞卡
  - 🕹️ 抓動物：聽聲音，在畫面上找出並抓對動物
  - 🫧 泡泡射擊：泡泡飄動時戳破正確的目標動物

介面設計原則：大圖示、大按鈕（至少 80px 高）、大字（text-2xl 以上）、
圓角卡片，答錯不扣分不中斷，維持幼兒遊戲的低挫折感。

## 本機開發

```bash
npm install
cp .env.example .env
# 打開 .env，填入 BRONCI 帳號密碼（VITE_TTS_USERNAME、VITE_TTS_PASSWORD）
npm run dev
```

修改 `.env` 後記得要重新啟動 `npm run dev` 才會生效。

第一次使用時，瀏覽器需要手動信任 BRONCI 伺服器的憑證，打開下面這個網址，
點「進階 → 繼續前往（不安全）」：

- https://140.113.30.204:8461

## 部署到 Vercel

在 Vercel 專案的 Environment Variables 加入：

| 變數 | 說明 |
|---|---|
| `TTS_USERNAME` / `TTS_PASSWORD` | BRONCI 帳密（不加 VITE\_ 前綴，serverless 用） |
| `VITE_DEPLOY_MODE` | 固定填 `vercel` |

加完環境變數後要記得按 **Redeploy** 才會生效。

## 重要提醒

這個 App 是在雲端沙盒環境中開發的，沙盒對外連線無法連到陽明交大的
BRONCI 伺服器（140.113.30.204），所以程式碼雖然是照官方 API 規格撰寫，
沒有辦法在開發過程中實際測試發音是否成功，需要在你自己的電腦（校園網路
或已授權連線的環境）用 `npm run dev` 實測。
